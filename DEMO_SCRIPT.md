# Two-minute demo script

**Opening:** “The shortest route is not always the route someone wants at
night. Safe Route Finder makes the trade-off visible.”

**Show the map:** Green segments have a supplied streetlight pole within the
prototype’s 35 m reference radius. Red segments are unverified; they are not
proof of darkness.

**Run a route:** Set `Peenya pilot edge` to `Hebbal pilot edge`, choose
`21:20`, and set one traveller. Point out distance, safety score, lighting
coverage, police-proximity safety, and the route flag.

**Change the context:** Try `10:00`, then `02:00`. Explain that time changes the
calibration gradually: early night is not treated the same as deep night.

**Change the group:** Set four travellers. Explain the capped, diminishing
benefit and the explicit disclaimer that this is a model calibration, not a
guarantee.

**Close:** “The key design decision is transparency: we show what the data
supports, what is synthetic, and where the model is uncertain.”
